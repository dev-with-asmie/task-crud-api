# Task API

A simple RESTful CRUD API built with Node.js and Express.js for managing tasks.

## Features

- Create a new task
- Retrieve all tasks
- Retrieve a task by ID
- Update a task
- Delete a task
- Input validation
- Health check endpoint
- Swagger/OpenAPI documentation

## Technologies Used

- Node.js
- Express.js
- Swagger UI Express
- OpenAPI 3.0
