# Task API

A simple RESTful CRUD API built with Node.js, Express.js, and SQLite for managing tasks.

## Features

- Create a new task
- Retrieve all tasks
- Retrieve a task by ID
- Update a task
- Delete a task
- Input validation
- Health check endpoint
- Swagger/OpenAPI documentation
- SQLite database storage
- Persistent task data

## Technologies Used

- Node.js
- Express.js
- Swagger UI Express
- OpenAPI 3.0
- SQLite
- better-sqlite3
